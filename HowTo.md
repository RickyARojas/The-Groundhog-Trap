# How to Use The Groundhog Trap

## Overview

The Groundhog Trap is an AI governance prototype that evaluates prompts using multiple independent large language models before generating a final response.

The objective is to provide greater transparency and confidence through consensus, verification, and audit logging.

This document explains how to interact with the current prototype.

---

# Current Prototype

The current implementation is email-based.

There is no software to install.

Simply send an email containing your prompt.

---

# Step 1: Start a New Email

Create a new email message addressed to:

**groundhogtrap.ienf3m@zapiermail.com**

The subject line is optional.

---

# Step 2: Ask Your Question

Enter your prompt in the email body.

Examples include:

- Explain quantum computing in simple terms.
- Compare SQL and NoSQL databases.
- Why does consensus matter in AI governance?
- Explain the difference between supervised and unsupervised learning.
- Design an enterprise AI governance workflow.

The system accepts both simple and complex prompts.

---

# Step 3: Wait for Processing

After your email is received, the Groundhog Trap will:

1. Receive your prompt.
2. Create an audit record.
3. Send the prompt to multiple independent language models.
4. Compare responses for consensus.
5. Perform an LLM-as-a-Judge review.
6. Generate a final response.
7. Email the result back to you.

---

# Understanding the Response

Responses may include information such as:

- Final Answer
- Consensus Status
- Consensus Score
- Confidence Indicators
- Audit Information (future versions)

The exact format may evolve as the project develops.

---

# Suggested Test Prompts

The Groundhog Trap is designed to evaluate difficult questions.

Consider testing it with prompts that require:

- Reasoning
- Technical explanation
- Cross-domain knowledge
- Ambiguous scenarios
- Multi-step thinking

Examples:

- Explain why redundancy matters in safety-critical systems.
- Compare several approaches to AI governance.
- Explain a concept to both a beginner and an expert.
- Evaluate competing technical solutions.

# Beta Notice

This project is currently an engineering prototype.

Some responses may be incomplete or incorrect.

Your feedback helps improve future versions.

---

# Privacy Notice

Please **do not** submit:

- Passwords
- API keys
- Financial information
- Medical records
- Personally identifiable information (PII)
- Company confidential information
- Proprietary source code

The prototype maintains audit logs for debugging, evaluation, and continuous improvement.

Future versions are expected to incorporate additional privacy protections such as anonymized identifiers and enhanced audit controls.

---

# Known Limitations

Current limitations include:

- Email-only interface
- Prototype workflow
- Fixed model ensemble
- Limited telemetry
- No conversational memory
- Experimental consensus logic

These limitations are expected to improve as development continues.
